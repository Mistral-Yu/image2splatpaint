# Source Images

Input images used for local training and browser QA live here. Generated
renders, metrics, and exported models belong in `outputs/`.

The public repository contains `generated-geometric-sample.jpg` for the Sample
button and `ramen-photo.jpg` for quality benchmarks. Other images in this
directory are local test material and remain ignored by Git.

`generated-geometric-sample.jpg` is a generated geometric sample created for
this repository and distributed under the MIT License in the repository root.

`ramen-photo.jpg` is an original photo supplied by the repository author. The
author permits it to be redistributed as part of this repository under the MIT
License in the repository root.
